# Security reporting

Report sensitive vulnerabilities through the [LaraCoreKit private reporting channel](https://github.com/ProgrammerNomad/LaraCoreKit/security/advisories/new). Do not include credentials or exploitable details in public issues.

Stable releases are published on Packagist. Run dependency audits, keep demo mode out of customer deployments, use unique administrator credentials, and test application-specific authorization and uploads. Automated checks are not a completed independent security audit.
