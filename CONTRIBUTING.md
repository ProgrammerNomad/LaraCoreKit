# Contributing

Develop starter features in the main LaraCoreKit repository. PHP modules live under modules/; frontend source lives under resources/ and modules/UIShowcase/. Website-only work belongs in ProgrammerNomad/laracorekit-website.

Follow README installation instructions, create a feature branch, and run composer test, composer pint-test, composer phpstan, composer audit --locked and npm audit. Rebuild assets with npm run build:core and npm run build when changing views/styles/scripts. Include migration and upgrade notes for user-facing changes. Report vulnerabilities privately according to SECURITY.md.
