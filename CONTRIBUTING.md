# Contributing

This repository is the distribution source for `programmernomad/laracorekit`. Development is maintained in the [LaraCoreKit monorepo](https://github.com/ProgrammerNomad/LaraCoreKit), under `packages/core`.

Open source changes against the monorepo so the package, demo host, documentation and integration tests can be reviewed together. Follow its contribution guide and run tests, static analysis, formatting, dependency audits and the independent consumer smoke check. Keep website and demo code outside the package.
