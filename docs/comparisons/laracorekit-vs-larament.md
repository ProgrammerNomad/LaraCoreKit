# Choosing a Laravel foundation

LaraCoreKit combines a public frontend and Filament administration in a reusable package. It is useful when your application needs those features together and you accept the documented Laravel/PHP constraints.

Compare alternatives using their current official documentation and your own clean-install evaluation. This repository does not maintain a verified feature-by-feature comparison of third-party projects. Earlier comparative claims should not be used as evidence of security, performance or completeness.

Review [implemented features](/docs/introduction), [installation](/docs/installation) and [production requirements](/docs/deployment/production) before deciding.
