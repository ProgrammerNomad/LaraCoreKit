# UI showcase

Visit `/ui-showcase` in the GitHub host to browse examples organized by category. Categories are defined in `modules/UIShowcase/config/components.php`; views and routes live in that module.

The showcase is host-only. It does not imply that every demonstrated feature, including e-commerce or advanced charts, has an implemented application backend. Copy/adapt the examples you need into your own views.

The showcase has mobile navigation and theme switching. Its Chart.js, Sortable and Prism dependencies load through a separate Vite entry rather than on all public pages.

See [installation](/docs/installation) and [package architecture](/docs/core/architecture).
