# Frontend components

The reusable package includes its locale selector and public application views. The repository's UIShowcase contains additional interface examples for developers to explore; its routes and JavaScript dependencies are not bundled into the Composer package.

Use showcase examples as starting points and adapt data, authorization, semantics, keyboard controls and responsive behavior for your application. An interface example is not a complete backend feature.

Keep Chart.js, Sortable and Prism in the showcase bundle. Ordinary website pages load the smaller base bundle. Livewire supplies Alpine for both.

See [installation](/docs/installation) and [package architecture](/docs/core/architecture).
