# Quick start

Choose the package for your own application or the GitHub host to explore the website, documentation and component showcase. The package includes public and admin features; it is not admin-only.

Follow the [installation guide](/docs/installation) for exact commands, release status and prerequisites. The package can be installed directly from GitHub now; the stable Packagist release is pending.

After installation, visit `/blog`, `/login` and `/admin`. Configure your own homepage. Create an administrator interactively with `php artisan laracorekit:admin`; there are no default production credentials.
