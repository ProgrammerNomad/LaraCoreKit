# Right-to-left layouts

The shared public layout sets `dir="rtl"` for Arabic and `ltr` otherwise. The website uses logical spacing where practical, and Filament supplies its own locale-aware interface.

Test your custom views, dropdown alignment, tables and embedded widgets in Arabic. Direction switching does not translate text automatically. The component showcase contains examples rather than a guarantee that every third-party widget is RTL compatible.

See [installation](/docs/installation) and [package architecture](/docs/core/architecture).
