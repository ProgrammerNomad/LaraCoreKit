# Search

The public Blog list includes database-backed text search over localized title/content fields. This is not a bundled external search service.

Scout, Meilisearch and other search integrations are optional application work. Add indexing, authorization-aware visibility, lifecycle updates and relevant tests before exposing a search service. Do not index drafts or future publications into a public index.

See [installation](/docs/installation) and [package architecture](/docs/core/architecture).
